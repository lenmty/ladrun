# Caleb Runner

Статическая браузерная игра без библиотек и сборки. Откройте `index.html` через локальный HTTP-сервер или опубликуйте папку проекта на GitHub Pages. Положите `Caleb.png` и `Wanderers.png` рядом с HTML и JS-файлами.

Для локального запуска из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Установка пакетов не требуется.

## Управление

- `Space`, `↑` или `W` — начать / прыгнуть.
- Удерживайте клавишу прыжка, чтобы набрать большую высоту.
- Удерживайте `↓` или `S` — пригнуться (на устройствах с coarse pointer пригибание отключено).
- После проигрыша `Space` или `Enter` начинает новую сессию.
- На мобильном первый запуск — тап по Калебу; после старта верхняя половина нижней части экрана прыгает (удержание даёт более высокий прыжок), нижняя половина пригибает. После проигрыша любой тап перезапускает игру.

Счёт растёт с пройденным расстоянием, скорость постепенно повышается, рекорд хранится в `localStorage`. Для смены языка используется язык браузера, светлая/тёмная тема следует настройке устройства.

## Файлы

- `index.html`, `style.css`, `game.js` — сцена и игровой цикл.
- `sprite-config.js` — source rectangles, категории, масштабы и hitbox из анализа спрайтов.
- `sprite-check.html` — отдельная страница проверки кадров.
- `SPRITE_ANALYSIS.md` — документация по исходным спрайтам.
